01 / Make one

Build a pluginand list it here.

Shell, Python or Node, for anything Lerd doesn't do on its own: your team's tools, a debug bar, a dashboard for the one service you always open.

  1. 01

    Build it

    Start from a working plugin that uses every surface, or ask your AI assistant: Lerd's MCP server carries the plugin guide.

    $lerd plugin new my-plugin
  2. 02

    Publish it

    Put it in a public git repository with a README, a license and a screenshot of what it adds.

  3. 03

    Submit it

    Open a pull request on lerd-env/plugins naming one commit. A maintainer reads it, and that commit is what everyone installs.
